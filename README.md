# Norsk · 挪威语学习书房

访问网站：https://gasen1216.github.io/norsk-study-pages/

无需登录即可阅读教材与练习册、听读课文、学习原书 Ordliste 和基础知识。

阅读支持整页适应屏幕、缩放及全屏。新增“双页对照”：左侧教材、右侧练习册，各自有可隐藏的完整目录、页码跳转、缩放和阅读位置保存；手机可切换两侧。目录独立滚动，页脚固定在侧栏底部。基础分类按由易到难排列。所有单词读音均可调速，读速自动保存。练习提供翻面词卡、拼写学习、综合测验、配对消除与听音选义；点击卡片后再选择整章、小节或基础分类，全部去重词进入一轮。练习界面只保留进度、读速、音效和退出；无论答对答错，作答后都会朗读正确的挪威语。没记住的词会进入重练，再错就排到队尾，直到答对。听音选义先播放读音再选释义，配对分左右两列并自动进入下一组。拼写使用可点的挪威语键盘；答对、答错、连对和完成都有简短音效与动画，支持静音及减少动画偏好。组合、进度和首次成绩保存在当前浏览器，可从历史页导出备份。

练习卡片下方左侧是学习记录，右侧直接显示排行榜和自己的等级：网站开着且在前台时每分钟 +2 XP（每天最多 240），五种练习都加经验，等级以星星、月亮、太阳、皇冠显示；提供本周榜、总榜及修改昵称，无需登录。主站和备用站均连接同一个云端数据库；设备身份按当前网站和浏览器保存，清除网站数据后会生成新身份。详情见 [练习设计与验证](docs/practice-redesign.md)。

教材第 1–15 章整章录音已齐全，另提供 74 段原声分节及 8.5、8.6 两段明确标注的合成补读。第 9–15 章新增 35 个小节，可从教材目录和双页对照中独立播放。

本仓库存放可直接发布的网站文件。GitHub Pages 使用 main 分支根目录，提交更新后自动发布。
