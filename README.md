# Norsk · 挪威语学习书房

访问网站：https://gasen1216.github.io/norsk-study-pages/

无需登录即可阅读教材与练习册、听读课文、学习原书 Ordliste 和基础知识。

阅读支持整页适应屏幕、缩放及全屏。新增“双页对照”：左侧教材、右侧练习册，各自有可隐藏的完整目录、页码跳转、缩放和阅读位置保存；手机可切换两侧。目录独立滚动，页脚固定在侧栏底部。基础分类按由易到难排列。所有单词读音均可调速，读速自动保存。练习可任意组合整章、小节与基础分类，全部选中词进入一轮，自动播放读音，查看词卡并复习薄弱词；常用组合、未完成进度和成绩保存在当前浏览器，可从历史页导出备份。

本仓库存放可直接发布的网站文件。GitHub Pages 使用 main 分支根目录，提交更新后自动发布。

教材、练习册、PPT 和原录音的权利属于相应作者与出版方；NB Uttale 词典数据采用 CC0，PDF.js 采用 Apache-2.0（许可证见 vendor/PDFJS-LICENSE）。
