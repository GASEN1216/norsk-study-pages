# 练习区更新 · 2026-10-22

练习首页采用暖白、深绿和细边框，首页集中显示五种玩法卡片。点卡片后才进入范围弹窗，整章可直接勾选，小节按需展开；底部直接开始。上次范围自动记住，排序、读速、题型和常用范围收进更多选项。练习中隐藏重复的目录和页标题，反馈留在题卡内。桌面和手机使用同一套操作顺序。

参考了 [Duolingo 练习中心](https://blog.duolingo.com/guide-to-duolingo-practice-hub/) 按技能选择练习的方式、[GOV.UK 按钮指南](https://design-system.service.gov.uk/components/button/) 对主要操作的区分，以及 [NN/g 渐进披露](https://www.nngroup.com/articles/progressive-disclosure/) 将详细设置移到次级界面的原则。视觉沿用现有书房配色。

视频中的英语释义替换为本站已有中文释义；现有词表没有配图，题目使用词语和释义。保留原有“选中全部去重词进入一轮”的规则，不照搬视频中 12 题的上限。拼写统一为看中文写挪威语；测验的方向设置适用于判断和选择。候选词不足四个时，选择题回退为拼写，页面说明这一行为。

## 记录与判分

继续使用 `norsk-practice-v1`，缺少玩法字段的旧进度仍按听音处理。已保存组合、首答记录和旧练习队列可继续使用。新增玩法、收藏、测验选项、输入草稿、配对局面和计时一并保存在浏览器本地；导出包含这些记录。

拼写接受大小写、首尾空白、连续空白、Unicode 组合形式和句尾标点差异，保留词间边界以及 æ、ø、å 的区别。相同完整中文题面的同池词可作为另一正确答案；只共享某个义项的词不会被无限放宽。配对把义项重叠的词分到不同小组，避免同义词产生不可完成的局面。

## 验证

`npm run check` 包含旧练习状态回归和新增玩法检查。新增检查覆盖五种模式、旧记录兼容、首答锁定、同题面多答案、候选不足、关闭答案时的读音限制、配对错配/暂停/续练/最佳记录、词表更新恢复、收藏与输入草稿。

浏览器验收使用独立本地预览端口，实际完成综合测验和两组配对，并检查词卡、收藏、拼写输入、刷新续练和手机布局，避免改动常用预览地址已有的学习记录。

本次练习检查 38 项、加载检查 5 项、双页阅读检查 15 项通过；排行榜前端检查 21 组、服务端真实 HTTP/SQLite 检查 14 组通过。完整 2,054 个去重词的混合题生成，经本机基准验证由约 74 秒降至约 20 毫秒；缓存词义拆分，并只寻找当前题型需要的干扰项。全量发布资料校验通过，包含 481 页 PDF、15 章音频、91 个可解码录音文件与 2,054 个独立单词读音。

补充验证了 320 和 390 像素手机布局、卡片进入范围后开始、键盘光标编辑和草稿恢复、完成一轮后实际计分、刷新保留昵称、周榜和总榜切换。断网或排行榜模块初次加载失败时，新成绩保留待提交标记；恢复后幂等补交，不将旧历史自动上传。首次同时打开多个标签页时，通过 Web Locks 或 IndexedDB 事务串行创建身份，避免同一浏览器意外分成两个排名身份。

## 点击键盘与排行榜

拼写学习和综合测验的拼写题提供屏幕键盘，包含 æ、ø、å、é，数字、标点、空格和退格。沿用真实输入框，支持选区替换、光标中间编辑、设备键盘切换和刷新草稿恢复；屏幕键盘使用 inputmode=none 避免手机同时弹出系统键盘。提交后收起键盘，焦点移到“继续”，连续正确答案显示简短反馈。参考 [Duolingo 写作练习与键盘切换](https://blog.duolingo.com/covering-all-the-bases-duolingos-approach-to-writing-skills/) 的交互原则。

排行榜入口与学习记录并列，使用本周榜和总榜，顶部直接改昵称。按用户要求使用随机设备身份，无需登录，不读取硬件指纹；同一浏览器保留身份，不同浏览器或清除存储会获得新身份。受 [Duolingo 周榜](https://blog.duolingo.com/duolingo-leagues-leaderboards/) 启发，练习首答计入参与积分和正确积分，自评词卡不参与排名。

排行榜前端与 Python/SQLite 本地服务一并提供。正式网站已接入 Sites 的 Worker/D1 云端服务，主站和备用站使用同一个数据库，本地预览继续使用隔离的同源 /api/community。云端服务通过 114 项真实 HTTP 断言及 D1 数据完整性检查，正式端点已验证两个独立匿名设备的注册、改名保存和两个网站的跨域连接。无服务时明确显示暂不可用，不填充示例名次。详见 [排行榜上线说明](community-deployment.md)。

## 答题音效与即时反馈

拼写学习、综合测验和配对消除在实际作答后给出短促反馈：答对显示对勾与柔和绿光，答错显示重试提示并轻晃；连续答对 3 题及之后每 5 题有进阶提示音与连对标记。配对成功的重试也有成功反馈，首答评分与错配加时继续按原规则计算。自评词卡使用中性记录提示，不将“再练一次”当成客观答错。

音效使用浏览器 Web Audio 即时合成，不请求额外音频文件。正确、错误、连对、完成采用不同的短音序列；首页底部和练习顶部提供持久保存的音效开关。首次真实点击或按键才建立音频上下文；暂停、离开、切到后台或静音会清理正在播放的提示音。切换音效仅更新开关，不重建输入框，保留输入草稿、光标和选区。浏览器不支持音频或阻止播放时，仍可正常练习并看到文字反馈。

完成练习时，成绩卡播放一次短彩纸效果与完成音；查看历史、刷新、恢复练习和普通重绘均不重复播放答案或完成效果。系统开启减少动画时保留文字与音效，跳过晃动、缩放、发光和彩纸。补充的 4 组集成检查覆盖真实手势解锁、四类音效、重复事件锁定、静音持久及输入保护、配对重试评分、暂停与离开清理、减少动画和音频不可用降级；现有练习检查与 25 组玩法检查通过。
